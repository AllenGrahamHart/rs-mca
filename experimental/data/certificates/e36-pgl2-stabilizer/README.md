# E36 PGL2 Stabilizer Certificate

This certificate records the E36 finite check for
`f_dih_subgroup_completeness`.

Verifier:

```bash
python3 experimental/scripts/verify_e36_pgl2_stabilizer.py
```

The verifier covers every distinct coset domain `alpha * mu_n` for:

- `F_17`, with `n = 4, 8, 16`;
- `F_97`, with `n = 4, 8, 16, 32`.

For each row it enumerates the full set-stabilizer in `PGL_2(F_q)` by
three-point determination: a projective linear map is fixed by the images of
three distinct domain points, so every ordered target triple is tested.  The
expected stabilizer is the dihedral group generated by rotations
`x -> zeta x` and coset inversions `x -> alpha^2 zeta / x`.

Result: all 52 checked coset domains have stabilizer exactly dihedral; the
exception list is empty.
