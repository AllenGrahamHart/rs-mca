# F4 Switch-Net Hunt Certificate

This certificate records the exact characteristic-`p` switch-net hunt for DAG
node `u1_pullback_dichotomy`.

Run:

```bash
python3 experimental/scripts/verify_f4_switch_net_hunt.py
```

The verifier enumerates the registered tame toy rows, searches for disjoint
identical-defect gadget families with `C(R,p) > n^2`, and checks that no
v1-uncharged dangerous family is present.
