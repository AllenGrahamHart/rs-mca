# H1 U1 Toy Harness Certificate

This certificate records the H1 toy harness for DAG node
`u1_pullback_dichotomy`.

Run:

```bash
python3 experimental/scripts/verify_h1_u1_toy_harness.py
```

The verifier enumerates same-top-`t` locator families on the registered toy
rows, checks the canonical star-PTE normal form, strips the explicit v1
quotient/dihedral pullback filters, and verifies the per-base `n^2` survivor
cap.
