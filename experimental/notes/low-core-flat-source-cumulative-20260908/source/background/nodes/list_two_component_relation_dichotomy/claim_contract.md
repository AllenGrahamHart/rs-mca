# Claim contract

The scalar-tail companion proves an UPPER bound, not another exact
maximum identity. It uses two independent constant projection rows;
inside a fixed first fiber, the second projection is injective.
The stronger threshold is exactly b=2a-k+1, with the SAME code k.
Scalar list sizes above n are zero. Empty projected lists force an
empty joint list. Uniform inputs U,V must themselves be proved upper
bounds before U+(U-1)V can be compared to any prize budget.

Object: distinct two-component codeword pairs, on one common agreement
set. Parameters: one field F, a distinct n-point domain D in F,
1<=k<=a<=n, code degree <k, closed agreement threshold >=a.

The row space uses degree <=a-k coefficients and the actual remainder
modulo P_D. It is determined solely by the received pair modulo the
code. Rational-function rank is not coefficient-field dimension,
correction rank, support rank, or a chosen upstream ledger's rank.

Every row constrains every list member by a polynomial identity.
Nonprimitive rows are allowed. Their gcd must divide the polynomial
right side. Forced incompatible gcd-root coordinates are deleted
before scalarization; the agreement threshold is NOT decreased.
Primitive row degree >=k yields a singleton bound, not a negative-
dimension RS code. Empty polynomial solution sets give empty lists.

The complete scalar correspondence has code dimension k-d on D'.
Only the final upper comparison extends the scalar receiver to D and
embeds that code into RS[k]. It is not a bijection to the full-domain
RS[k] list. The worst-case identity max(M_1,M_0) nevertheless is exact.

The relation-free class is defined by the entire bounded row kernel
being zero. Testing one row, one support, a sample, or a rank heuristic
does not establish it. No computation or fast full-kernel construction
is claimed. The dimension gate is strict.

No uniform prize bound on either M_1 or M_0 is proved. Smoothness is
not needed. Field descent, arity beyond two, slope counting, prize
budgets, and adjacent endpoints require separate consumer theorems.
