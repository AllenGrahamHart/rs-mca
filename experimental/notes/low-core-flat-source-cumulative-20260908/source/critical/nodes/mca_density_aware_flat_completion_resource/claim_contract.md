# Claim Contract

- Object: actual ordered polynomial-evaluation bases; MCA use counts original slopes.
- Field: unchanged, arbitrary field with the stated distinct evaluation points.
- Rank: actual s, proper maximum-density flat rank 1<=j<s.
- Core: M nonzero evaluations, t inside the complete flat set A, a<c=M-K+1.
- Quotient: actual rank s-j, degree <K-a, gap M-K+a-t.
- Inputs: any proved uniform quotient-basis lower count; no guessed bound.
- Signs: actual inside tuple extension identity and coupled ratio bounds.
- Box: real relaxation only; positivity is required before multiplying lower bounds.
- MCA: existing full-code badness, empty universal core and original defect insertion.
- Nonclaims: no finite row, rank bound, receiver descent, owner atom or Prize closure.
