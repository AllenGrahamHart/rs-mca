# Audit

Hand checks trace dimension to the standalone elliptic-section proof,
coefficient degree to the original 2s-dimensional embedding, and label
ownership to the complete-core telescoping argument. No transformed
coordinate height or finite-field point sample replaces a geometric step.

`verify.py` computes the 500-term rational gain and the finite consumer's
resource endpoints. `verify_audit.py` recomputes the gain through an
integer common denominator, rejects an insufficient ceiling, and checks
the elementary polynomial controls from the geometry supplier. It also
checks the degree-seven ordinary/exceptional compositions numerically.
Neither program proves the surface theorem, the generic dimension bound,
or that an arbitrary source has an affordable factor cover.

The singular cusp and constant elliptic curve are explicit algebraic
controls against dropping smoothness and claiming universal rigidity.
The scaled constant cubic with discriminant 64X^12 rejects a false
rigidity certificate based on a nonminimal equation. The finite resource
is inherited from Hughes's #1168/#1174 margin theorem, not claimed new.
The moving-j cubic example is classified coefficientwise, not by a large
search. Independent external hand review remains due. This local theorem
is not yet in the immutable 23844ac8 upstream review packet.
