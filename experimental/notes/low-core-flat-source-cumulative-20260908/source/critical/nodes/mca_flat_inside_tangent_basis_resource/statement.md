Status: PROVED by the hand argument; independent external review remains due.

Use the actual dimension-eleven carrier, maximum-density flat and notation
of the required maximum-density core-basis theorem. Allow any 1<=j<=10,
but assume a<c=M-K+1. For an M-point joint-core subset let t be its

    P(X)=X*prod_(i=1)^(l-1)(X-min(K-a-l+i,i*h)).

    L_k=p^k+k*q*p^(k-1), D_k=k*p^(k-1),

    G_q(t,h)=(c-t)^j+11*L_(j-1)*t

maximized with the existing hybrid/coupled counts; a consumer using it
as a positive tuple charge must prove positivity. No rank-six coefficient
is discarded merely because it has an inconvenient sign.

joint core H has at least M=m-T points. If H meets A in exactly t
points, an M-point core subset can be chosen to contain ALL those t
points. It need not lie inside the old selected witness. Inserting any
one of that witness's actual defects gives twelve times the proved
basis bound in ORIGINAL independent incidence tuples. The original
explanation, slope label and minimizing pair are unchanged.

Consequently a heavy group's own occupancy interval can supply a lower

    |Gamma| <= T_up/beta_L
                 +max(0,1-beta_H/beta_L)*Q_H.       (TWO-COST)

including HIGH records. This is a same-source counting statement, not
