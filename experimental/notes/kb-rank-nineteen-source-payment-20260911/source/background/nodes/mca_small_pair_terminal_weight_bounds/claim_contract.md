# Contract

Input: one original MCA assignment, degrees<J, original N=R+J,
complete cores>=d+J-t, raw<=t original weights and valid source pencil gates.
All counts refer to actual represented pairs; each finite label has one owner.

Output: integer population line envelopes, a single global nonconstant
inside-coordinate charge, and c<=3 terminal bounds from determinant incidence
or same-field shared-carrier joint LIST. Every per-pair count is multiplied
by the original raw cap R-d+t. Scalar padding retains its own core-union roots.

No source gates, terminal allowance or full-row payment are proved here.
The determinant denominator must be positive; same-field padding must fit.
Falsifiers: repeated inside-coordinate charges for different original owners,
an integer population exceeding the printed cap, or an invalid joint LIST
dimension/substitution. A line envelope is an upper bound, not a witness.
