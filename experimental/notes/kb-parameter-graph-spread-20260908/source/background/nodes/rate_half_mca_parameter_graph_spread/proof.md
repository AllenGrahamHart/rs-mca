## Scope And Provenance

The rank gauge and padded-Johnson cap are credited existing results, not
new discoveries. This theorem applies them to EVERY proper hyperplane of
the actual slope/explanation graph, quantifies the original-label spread,
and prices possible rank loss after the already used secant exceptions.

The previous tuple proofs correctly allowed survivors to span less for
arbitrary sources. This theorem does not contradict them: such a collapse
is now explicitly paid, and therefore cannot occur on an over-budget
source in the declared original rank-twelve residual. It does not identify
which low-cost records share hyperplanes, count those hyperplanes, or
bound full-dimensional label families. Those are substantive remaining
obligations, not speculative prerequisites added to this node.
