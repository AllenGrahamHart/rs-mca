# Audit

Hand checks: non-eigenvector differences span TWO polynomials, whose
annihilator is a projective point only because dim U=3. Eigenvectors
require the separate root mask. Joint-rank-one coordinates need not be
removed. Common zeros must be removed in the nonsplit case.

The same original n-A weights are used after the auxiliary deletion.
Worst-deletion monotonicity uses the positive denominator explicitly.
F-eigenvalues are not replaced by eigenvalues in an algebraic closure.

The small verifier checks split, partially split, nilpotent/Jordan and
nonsplit controls, common zeros, and the earlier generic-singleton/triple
fibre phenomenon. These are algebraic controls, not official MCA sources
or a sampling proof of the universal theorem. External review remains due.
