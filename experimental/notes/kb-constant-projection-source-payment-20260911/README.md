## Reusable Counting Lemma

The [generic lemma](source/background/nodes/mca_constant_projection_singleton_fibre_census/statement.md)
separates singleton projection fibres from fibres containing at least two
actual pairs. If complete cores have size >=A and polynomial degree <K,
a rich fibre's complete union complement satisfies e<=n-2*A+K-1.

    Omega_t <= t + (n-A)*Q(n-A) + sum_bins u*P(l)*Q(u).

Q counts projected polynomials; P counts scalar parameters on a fibre's
OWN union. The inside charge t is global, across all fibres.
No quotient-one assumption or shared fibre-mass packing budget is needed.
