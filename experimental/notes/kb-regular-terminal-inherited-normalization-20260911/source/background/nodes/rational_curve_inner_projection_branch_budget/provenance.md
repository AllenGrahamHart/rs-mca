# Provenance

Motivated by classical Segre projection-centre estimates. Noma's
[2024 article metadata and abstract](https://ynu.repo.nii.ac.jp/records/2001089)
explicitly concern characteristic zero. That theorem is NOT imported as
a proof in the official finite field.

The local proof reconstructs low-degree inner birationality with a
scheme-length/separability argument and derives the branch charges using
the existing planar genus supplier. The branch-weighted ORIGINAL-coordinate
conversion and its singular-centre guard are explicit additions for this
source-selection application. No PR status or numerical scan is a supplier.
