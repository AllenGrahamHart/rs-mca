# A Proved Guard, Not Yet An Affordable Global Schedule

At one of the first eight rank19 prefixes (4<=s<=11), let V have
dimension s, W dimension r>s, and actual
primitive normalization/image degrees nu,d_image. Let H>=nu be a desired
normalization ceiling. Put h=floor(H/nu)+1>=2 and let B_geo be the branch-
weighted coordinate bound from the Segre supplier with ambient dimension
s-1. Its refinement is zero if d_image-h*(s-2)<1.

Outside those high-degree inner centres, mu<h and the child has
nu_child=nu*mu<=H. Singular centres are included via branch count; using
the number of image centres alone is not a valid coordinate bound.

The existing regular-anchor bad set has at most B_reg=K+s-r coordinates
and contains every common zero. On their union with the geometric bad
coordinates, use B=min(n,B_reg+B_geo). If B<A, then for any uniform bound
L on retained actual child weights the original incidence count gives

    total original weight <= (n-B)/(A-B)*L.

Every retained child is joint-rank-two and remains generically regular,
and its normalization ceiling is preserved. Full gcd removal in the
geometric description changes no original assignment or weight.

The EXTRA B_geo changes the anchor cost. Generic birationality alone does
not set it to zero, and an unaffordable or nonpositive denominator cannot
be used. A complete finite schedule preserving original source allowances
is still missing. No speculative conditional node was introduced for it.
