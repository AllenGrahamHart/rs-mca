# X74: h=4 normalized-sieve orbit bound

- **DAG node:** `x74_h4_sieve_orbit_bound`.
- **Consumer:** `active_core_count_bound`.
- **Status:** proved h=4 counting consequence.
- **Verifier:** `experimental/scripts/verify_x74_h4_sieve_orbit_bound.py`.
- **Certificate:**
  `experimental/data/certificates/x74-h4-sieve-orbit-bound/x74_h4_sieve_orbit_bound.json`.

## Statement

For every 2-power row `n = 2^s` with odd `p == 1 mod n`, the primitive h=4
norm-gate residue in X65 canonical-orbit currency satisfies

```text
# primitive h=4 canonical orbits < n^3.
```

More precisely,

```text
# primitive h=4 canonical orbits
  <= 2 phi(n)^2 (n-1)
  = n^2 (n-1) / 2
  < n^3.
```

## Proof

X73 reduces row-local h=4 norm-gate certification to normalized interval
pairs.  Each survivor has the form

```text
q(X) = 1 + eps * (X^a + X^(a+1) + ... + X^(a+ell-1)),
eps in {+1,-1},
1 <= ell <= n-1.
```

Fix a primitive root `y = zeta^u`, a sign `eps`, and a length `ell`.  Since
`ell` is not a multiple of `n`,

```text
1 - y^ell != 0.
```

The equation `q(y)=0` is

```text
1 + eps * y^a * (1-y^ell)/(1-y) = 0,
```

so

```text
y^a = - (1-y) / (eps * (1-y^ell)).
```

Thus the start exponent `a` is forced modulo `n` if it exists.  It may fail
to lie in the allowed interval range, but it cannot produce more than one
normalized pair for the fixed `(u, eps, ell)`.  Therefore

```text
# survivor normalized pairs <= 2 phi(n)(n-1).
```

Each X68 certifier key contains at least one survivor normalized pair, so

```text
# survivor X68 keys <= 2 phi(n)(n-1).
```

Now compare X68 key currency with X65 row-count currency.  An X68 key is
generated by:

```text
unit scaling in (Z/nZ)^*, followed by the eight X64 chord transforms.
```

X65 already quotients by the eight X64 transforms.  Hence, after passing to
X64 canonical row representatives, one X68 key contains at most `phi(n)`
primitive canonical row representatives.  Consequently,

```text
# primitive canonical orbits
  <= phi(n) * # survivor keys
  <= 2 phi(n)^2 (n-1).
```

For `n = 2^s`,

```text
phi(n) = n/2,
```

so the right side is

```text
n^2 (n-1) / 2 < n^3.
```

This proves the h=4 primitive norm-gate branch fits the rewired L3
`n^3` column in X65 canonical-orbit currency.

normalized-pair sieve into a row-count theorem with the right exponent.

## Consequence

For h=4, the primitive finite-p norm-gate branch is no longer a possible
source of super-`n^3` mass.  The remaining terminal node still includes
larger h and the full active-core split-pair problem, but the h=4 centered
primitive residue now has a uniform polynomial bound in the same canonical
orbit currency used by X65.
