# Cyclic full-fiber collision lemma

- **DAG node:** `cyclic_fiber_collision_lemma`.
- **Consumer:** `active_core_count_bound`.
- **Status:** PROVED.
- **Verifier:** `experimental/scripts/verify_cyclic_fiber_collision_lemma.py`.
- **Certificate:**
  `experimental/data/certificates/cyclic-fiber-collision-lemma/cyclic_fiber_collision_lemma.json`.

## Statement

Let `H = mu_n` in a field whose characteristic is prime to `n`.  Let `h` be a
proper divisor of `n`, and put `m = n/h`.  For each `0 <= r < m`, define the
full cyclic fiber

```text
P_r = { zeta^(r + m k) : 0 <= k < h }.
```

Then the locator of `P_r` is

```text
L_r(X) = X^h - zeta^(r h).
```

Consequently all intermediate elementary symmetric sums vanish:

```text
e_i(P_r) = 0,        1 <= i <= h-1.
```

Thus every two fibers `P_r, P_s` form a same-top-`(h-1)` split-pair
collision.  Every such collision is paid by the cyclic pullback dictionary:
it is a pair of fibers of the map

```text
psi(X) = X^h.
```

## Proof

The subgroup `mu_h` inside `mu_n` is generated by `zeta^m`, since
`m = n/h`.  Its coset `P_r = zeta^r mu_h` is exactly the set of solutions in
`H` to

```text
X^h = zeta^(r h).
```

The polynomial `X^h - zeta^(r h)` has degree `h` and has precisely the `h`
distinct roots in `P_r`, because the characteristic is prime to `h`.  Therefore
it is the monic locator of `P_r`.

Expanding the monic locator in elementary-symmetric coordinates,

```text
L_r(X) = X^h - e_1(P_r) X^(h-1) + e_2(P_r) X^(h-2)
         - ... + (-1)^h e_h(P_r),
```

and comparing with `X^h - zeta^(r h)` gives

```text
e_1(P_r) = ... = e_(h-1)(P_r) = 0.
```

If `r != s`, the constants `zeta^(r h)` and `zeta^(s h)` are distinct for
`0 <= r,s < m`, so the fibers are distinct.  They share the same top
`h-1` signature and their locators differ only in the constant term:

```text
L_r(X) - L_s(X) = zeta^(s h) - zeta^(r h).
```

This is exactly the split-pair condition.  Since all the sets are fibers of
`psi(X)=X^h`, the collision family is cyclic-pullback paid.

## Counts

There are `m = n/h` full fibers.  They form:

```text
ordered paid split pairs:       m(m-1)
unordered paid split pairs:     C(m,2)
anchored partners through mu_h: m-1
```

The X19 row is the special case `(n,h,m) = (32,8,4)`.  The anchored fiber is
`mu_8`, and the three other fibers are its cyclic-paid partners.  This is why
the X19 certificate reports one raw collision group, three anchored partner
pairs, and zero post-strip non-toral partners.

## Terminal-Node Consequence

Raw top-`(h-1)` signature injectivity is not a viable global terminal theorem:
it fails whenever `h` is a proper divisor of `n`.  The failure is harmless only
because it is already in the paid cyclic pullback class.

The terminal target should therefore remain in post-strip form:

```text
primitive row-wise split-pair residue <= n^3,
```

with the stronger high-q hope being post-strip vanishing.  The cyclic
full-fiber family belongs to the paid side of that dichotomy, not to the
primitive residue.
