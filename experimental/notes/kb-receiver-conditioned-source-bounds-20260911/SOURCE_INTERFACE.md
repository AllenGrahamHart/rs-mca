# Original Source And Counting Contract

This is a reading aid for the frozen statements and proofs, not an
additional theorem or a weakening of their hypotheses.

## Receiver Colours

For a nonzero projective evaluation fibre, choose
ev_x=lambda_x*ell with lambda_x!=0. Partition it further by

    ((u(x)-h_*(x))/lambda_x, v(x)/lambda_x).

Changing the representative ell does not change equality of colours
inside that fibre. All class sizes w_i refer to this same fixed receiver
and carrier. In particular, they are NOT sizes of an arbitrary pair hull.

The colour proofs maximize raw over all admissible supports and scalar
explanations in this SAME carrier, independently for each original label.
This may change explanations, actual error rank and raw values.
The proof does not claim these are preserved, nor retest the old rank
hypothesis on the new selection.

Instead it proves the needed recordwise facts afresh: full-code badness
gives rank twelve to the incidence normals on a chosen support; literal
empty universal core gives nonzero evaluations on joint cores; an
independent ordered twelve-tuple determines one original label and
explanation. Tuples owned by different labels are disjoint.

At zero evaluations with v!=0, equality fixes one global label per
coordinate. Remove that set of labels ONCE; it has size at most
J-11<=21488. With v=0 such a coordinate cannot be a defect. This is not
an allowance per pair, colour class or case.

## Four Source Arguments

The dense-conic result keeps ANY valid original support/pair assignment.
For Q(X,Y,Z)=sum Q_ij(X)Y^i Z^j the degree gate is

    max_(Q_ij!=0) [deg Q_ij+(i+j)(J-1)] <=2J.

Its projective conic over F(X) must be nonsingular. Exceptions are the
actual coordinates with Q(x,u(x),v(x))!=0. The proof combines on-conic
pair counts and off-conic joint LIST sharing the SAME eleven-dimensional
polynomial carrier. It does not replace that dimension by the pair-space
dimension 22 or redefine original raw on the exception domain.
The terminal corollary's adjugate lift retains all coefficient roots and
requires density of the COMPLETE ORIGINAL core union.

For small colours, complete canonical defects lie in the sigma_43 bank.
An owned tuple must hit that bank, but may hit it in several positions.
The exact available count is (n)_12-(n-sigma_43)_12.

For bounded and sparse-heavy colours, a complete joint core sees one
receiver colour per projective evaluation fibre. Contract its whole LOCAL
core fibre, not a larger global fibre with unrelated receiver colours.
The small-raw core cost and the all-raw resource share one tuple universe.

If U/beta<W+1, a restricted tuple fraction multiplies W+1 BEFORE integer
rounding. Multiplying a pre-rounded W by that fraction is unjustified.

## Pointwise Profile Inequality

For the actual weights w_i let M=67470+J and let F_10 be the proved
rank-ten child basis bound. Define

    Phi_M(w)=min sum_i x_i F_10(J-w_i),
    0<=x_i<=w_i, sum_i x_i=M.

The minimizer fills the largest classes first, with a possibly partial
last class. This is only a LOWER bound for actual complete-core basis
costs; no realizability of that allocation is asserted.

With the original beta44(J), put

    alpha=max(12*Phi_M(w), beta44),
    eta=min(alpha, 3*beta44/2),
    U_col=12!*e_12(w),
    V_col=12!*(e_12(w)-e_12(w with singleton classes deleted)),
    W=floor(U_col/eta), L=floor(V_col/alpha).

Then the original source satisfies

    source <= floor((W+min(W,L))/2)+(J-11)+134944.

Distinct-colour tuples are an UPPER universe: they need not all be
independent. The same actual profile supplies both upper and lower
counts. This inequality is proved, but it is not proved uniformly below
B*. The remaining work is to use actual owner/core incidence to control
the profiles and their attainable counts strongly enough.
